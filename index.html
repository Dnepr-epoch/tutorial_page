👤 THÀNH VIÊN 1: Pipeline & Data Ingestion Lead

Mục tiêu & Nhiệm vụ
  • Viết script tải tự động 12 tệp từ Inside Airbnb (listings, calendar, reviews cho 4 mốc).
  • Viết hàm lọc dữ liệu theo 1.000 listing và 5.000 review; gán 8 vùng A01–A08.
  • Viết script kiểm tra tự động (sanity_check.py) theo đúng các tiêu chí của đề bài.
  • Viết bộ khung điều phối run_pipeline.py.
Các tệp phụ trách tạo & code

src/download.py • src/filter.py • src/sanity_check.py • run_pipeline.py

Quy trình thao tác lệnh từng bước

1Tạo nhánh riêng và chuyển sang nhánh đó:

git checkout -b feat/download-filter-tv1

2Code nội dung các tệp trong thư mục src/:

  • Trong src/download.py: Đọc cấu hình từ configs/bangkok.yaml, tải 3 file nén mỗi mốc vào data/raw/<mốc>/.
  • Trong src/filter.py: Lọc ra đúng 1.000 listing_id và 5.000 review_id từ danh sách ID của nhóm. Gán cột analysis_area dựa trên tọa độ kinh/vĩ độ vào 8 vùng A01–A08.
  • Trong src/sanity_check.py: Viết các assertion kiểm tra:
    • Đúng 875 Entire home/apt và 125 Private room.
    • number_of_reviews = 0 lần lượt là 50, 30, 25, 25.
    • Mốc cuối thiếu đúng 20 giá.
    • Mỗi vùng có 120–130 listing.

3Chạy thử trên máy cục bộ:

python src/download.py
python src/filter.py
python src/sanity_check.py

(Nếu màn hình in ra "Sanity Check Passed" là đạt).

4Lưu và đẩy lên GitHub:

git add src/download.py src/filter.py src/sanity_check.py run_pipeline.py AI_USAGE.md
git commit -m "feat(ingest): hoan thien download, loc du lieu va sanity check"
git push origin feat/download-filter-tv1

5Mở Pull Request (PR):

Lên web GitHub, bấm Compare & pull request → Gửi PR vào main → Tag TV2 vào review code.

👤 THÀNH VIÊN 2: Data QA & Cleaning Specialist

Mục tiêu & Nhiệm vụ
  • Khảo sát dữ liệu, lập từ điển dữ liệu (reports/data_dictionary.md).
  • Viết bộ quy tắc làm sạch dữ liệu trong src/qa.py.
  • Xuất báo cáo kết quả làm sạch ra reports/qa_report.csv.
Các tệp phụ trách tạo & code

src/qa.py • reports/qa_report.csv • reports/data_dictionary.md

Quy trình thao tác lệnh từng bước

1Kéo dữ liệu đã lọc từ TV1 và tạo nhánh:

git checkout main
git pull origin main
git checkout -b feat/qa-cleaning-tv2

2Code nội dung src/qa.py:

  • Chuẩn hóa giá: Chuyển chuỗi tiền tệ (ví dụ ฿1,500.00 hoặc $1,500.00) sang số thực float.
  • Xử lý 20 dòng thiếu giá ở mốc 4: Tạo cờ flag_missing_price = True, điền giá trị thay thế (imputation) bằng trung vị của cùng loại phòng trong cùng vùng.
  • Xử lý ngoại lai (Outliers): Gắn cờ các phòng có giá vượt ngưỡng trần THB hoặc số đêm tối thiểu minimum_nights > 365.
  • Xuất báo cáo: Lưu các thống kê (số dòng vi phạm, KPI trước/sau khi sửa) vào reports/qa_report.csv.
  • Lưu dữ liệu đã làm sạch vào data/processed/ (định dạng parquet hoặc csv).

3Chạy thử trên máy:

python src/qa.py

4Lưu và đẩy lên GitHub:

git add src/qa.py reports/qa_report.csv reports/data_dictionary.md AI_USAGE.md
git commit -m "feat(qa): hoan thien bo quy tac qa va xuat bao cao qa_report"
git push origin feat/qa-cleaning-tv2

👤 THÀNH VIÊN 3: Business Analytics & KPI Lead

Mục tiêu & Nhiệm vụ
  • Thiết kế và lập trình tính toán 5–8 chỉ số KPI thị trường Airbnb Bangkok phục vụ đối tượng đặt hàng (TAT / Hiệp hội Khách sạn).
  • Đảm bảo có KPI theo khu vực (analysis_area), theo thời gian (4 mốc), và kết hợp kết quả review.
  • Xuất kết quả ra data/processed/kpi_*.csv.
Các tệp phụ trách tạo & code

src/kpi.py • data/processed/kpi_summary.csv

Quy trình thao tác lệnh từng bước

1Cập nhật code sạch từ TV2 và tạo nhánh:

git checkout main
git pull origin main
git checkout -b feat/kpi-calculation-tv3

2Code nội dung src/kpi.py:

  • Đọc dữ liệu đã qua QA từ data/processed/.
  • Lập trình các hàm tính KPI:
    1. calc_adr(): Giá trung bình ngày theo từng vùng và từng mốc (THB).
    2. calc_occupancy_rate(): Tỷ lệ lấp đầy phòng ước tính theo từng tháng/quý từ bảng calendar.
    3. calc_revpau(): Doanh thu ước tính trên mỗi phòng có sẵn (ADR × Occupancy).
    4. calc_host_pro_rate(): Tỷ lệ chủ nhà chuyên nghiệp (sở hữu > 1 chỗ ở).
    5. calc_churn_rate(): Tỷ lệ chỗ ở rời bỏ / gia nhập thị trường qua 4 mốc.
  • Xuất toàn bộ bảng chỉ số ra data/processed/kpi_summary.csv.

3Chạy thử trên máy:

python src/kpi.py

4Lưu và đẩy lên GitHub:

git add src/kpi.py data/processed/kpi_summary.csv AI_USAGE.md
git commit -m "feat(kpi): hien thuc cac ham tinh toan kpi thi truong bangkok"
git push origin feat/kpi-calculation-tv3

5Mở Pull Request:

Gửi PR vào main, tag TV5 vào review để TV5 dùng dữ liệu vẽ biểu đồ.

👤 THÀNH VIÊN 4: NLP & LLM Engineer

Mục tiêu & Nhiệm vụ
  • Quản lý bộ dữ liệu 1.000 review mẫu LLM và 100 review nhãn tay.
  • Cùng nhóm dán nhãn 100 review vào data/samples/manual_labels_100.csv.
  • Viết phương pháp đối chứng (Baseline không dùng LLM) trong src/baseline.py.
  • Viết script gọi Gemini API trích xuất cảm xúc/khía cạnh có cache trong src/llm.py.
  • Đánh giá chất lượng (Accuracy, F1-score) trong src/evaluate.py.
Các tệp phụ trách tạo & code

data/samples/manual_labels_100.csv • src/baseline.py • src/llm.py • src/evaluate.py

Quy trình thao tác lệnh từng bước

1Tạo nhánh riêng:

git checkout main
git pull origin main
git checkout -b feat/llm-sentiment-tv4

2Triển khai code:

  • data/samples/manual_labels_100.csv: Điền nhãn tay cho 100 review (sentiment: positive/mixed/negative; khía cạnh: location, cleanliness, host, value, amenities, noise, safety).
  • src/baseline.py: Dùng từ điển hoặc NLP truyền thống (VADER/TextBlob/Rule-based) để phân loại.
  • src/llm.py: Lấy API key từ biến môi trường os.getenv("GEMINI_API_KEY"); trích xuất dạng JSON; lưu cache tại data/processed/llm_cache.jsonl; bổ sung cờ --skip-llm khi test.
  • src/evaluate.py: So sánh kết quả LLM và Baseline với 100 nhãn tay; tính Accuracy, Macro-F1; in báo cáo phân tích lỗi.

3Chạy thử trên máy:

python src/baseline.py
python src/llm.py
python src/evaluate.py

4Lưu và đẩy lên GitHub:

git add data/samples/manual_labels_100.csv src/baseline.py src/llm.py src/evaluate.py AI_USAGE.md
git commit -m "feat(llm): hoan thien pipeline llm, baseline va danh gia f1"
git push origin feat/llm-sentiment-tv4

5Mở Pull Request:

Gửi PR vào main, tag TV1 và TV5 vào review.
